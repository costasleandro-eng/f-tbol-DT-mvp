# Football Coach MVP

Mini web app inicial para generar sesiones de entrenamiento de fútbol según categoría, rama/contexto, nivel, objetivo, duración, jugadores, material y espacio. Incluye una primera canchita visual con jugadores, pelota y movimientos.

## Uso
Abrir `index.html` en el navegador o publicar en GitHub Pages.

## Archivos
- `index.html` — estructura de la app
- `styles.css` — estilos
- `script.js` — lógica del generador
